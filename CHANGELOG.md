# Changelog

## NotchSense V1

- Renamed the project from HardwareNotch to NotchSense.
- Removed Top and Bottom edges; only Left and Right are supported.
- Added automatic Spanish/English UI selection from the Windows interface culture.
- Migrated legacy settings while preserving `StartWithWindows`.
- CPU/GPU rings represent load; RAM ring represents memory usage.
- No PawnIO or kernel driver is bundled or required by default.

This file contains public release notes only; internal development audits are kept out of the repository.
